# The Invisible Player: Brazil's Hidden Star

Interactive web project for Readathon 2026, based on *The Hour of the Star* by Clarice Lispector.

## How to open

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Sections

- `index.html`: welcome screen with `Start the Journey`.
- `locker.html`: Macabea's locker room with interactive objects.
- `quiz.html`: mini quiz for judges.
- `reflection.html`: written reflection and responsible AI statement.
- `qr.html`: printable QR page for judges.
